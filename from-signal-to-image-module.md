# 📓 Module 2: Signal Capture, Digital Detectors, and Image Formation

## 📝 Theory: From Physics to Pixels

If Module 1 taught us *how* the X-rays are generated and *why* tissues attenuate them, Module 2 teaches us *how* the detector reads this attenuated beam and *how* that physical measurement is converted into a digital, viewable image.

### 1. Detailed Beam-Matter Interactions (The Contrast Mechanism)

While simple attenuation is the macroscopic view, the microscopic interaction is what generates the electrical signal. When an X-ray photon interacts with the electrons of a tissue atom, three main events can occur:

#### A. Photoelectric Effect (Dominant Source of Signal)
*   **Mechanism:** A photon strikes an electron in an inner shell (K or L shell). The photon transfers *all* its energy to the electron, which is ejected from the atom. The photon ceases to exist.
*   **Dependence:** The probability of this effect is extremely high for high Z (high atomic number) materials and is highly dependent on photon energy ($E$).
*   **Image Contribution:** Because this process removes the photon entirely, the detected rate of photoelectric events is directly proportional to the differential attenuation, forming the basis of our contrast.

#### B. Compton Scattering
*   **Mechanism:** A photon strikes a loosely bound electron, transferring only *part* of its energy, causing the electron to recoil (Compton scattered). The photon changes direction and loses energy.
*   **Image Contribution:** Scattered photons degrade image quality by contributing to "noise" and blurring the contrast. Modern detectors are designed to reject these scatter events.

#### C. Coherent Scattering (Elastic Scattering)
*   **Mechanism:** The photon interacts with the electron cloud but is scattered without losing significant energy.
*   **Significance:** It contributes to the overall scatter background but is generally accounted for in signal processing, rather than being the primary source of the image signal.

### 2. Digital Detection Systems (Detector Physics)

Modern digital systems (like flat-panel detectors) convert X-ray energy into an electrical charge. The amount of charge collected at any point (a pixel) is proportional to the number of primary X-rays that passed through that location.

*   **Pixel:** The smallest measurable unit of area in the detector.
*   **Signal:** The electrical charge generated by the absorbed X-rays.
*   **DQE (Detective Quantum Efficiency):** A critical metric indicating how efficiently the detector converts the available X-ray quanta into a measurable signal. High DQE means less radiation is needed to get a quality image.

### 3. Image Processing and Standardization

The raw electrical signal must be processed to create a usable image.

*   **Windowing/Leveling:** Adjusting the digital contrast and brightness displayed to best visualize the tissue structures of interest (e.g., chest X-rays require different window settings than chest CT scans).
*   **Bit Depth:** The number of bits used to quantify the signal (e.g., 12-bit or 16-bit depth) determines the dynamic range and grayscale accuracy of the resulting image, allowing for subtle variations in density to be distinguished.

### 🖥️ Code Implementation: Image Simulation (Python)

To illustrate the concepts, we will simulate the raw signal data (pixel intensity) based on simulated absorption.

```python
import numpy as np
import matplotlib.pyplot as plt

# --- Constants ---
IMAGE_SIZE = 100  # 100x100 pixels
BIT_DEPTH = 12    # Simulated 12-bit depth (0 to 4095)

def simulate_absorption(pixel_data):
    """
    Simulates the differential absorption across the image plane.
    Intensity is inversely proportional to absorption.
    """
    # Create a base gradient representing variable material density
    # Low values = high absorption (dense material)
    # High values = low absorption (less dense material)
    y, x = np.meshgrid(np.linspace(0, 1, IMAGE_SIZE), np.linspace(0, 1, IMAGE_SIZE))
    # Simulate a denser object in the center
    absorption_map = np.exp(((x - 0.5)**2 + (y - 0.5)**2) / 0.01) * 0.8 + 0.1
    
    # Simulate the Raw Signal (Signal_Pixel ~ 1 / Absorption)
    raw_signal = 1 / absorption_map
    
    # Normalize the signal to simulate the limited bit depth of the detector
    signal_pixels = (raw_signal - raw_signal.min()) / (raw_signal.max() - raw_signal.min()) * (2**BIT_DEPTH - 1)
    
    return signal_pixels

def apply_processing(raw_signal):
    """
    Simulates Image Processing steps: Clipping and Windowing.
    """
    # 1. Clipping: Ensuring the signal stays within the defined bit depth
    clipped_signal = np.clip(raw_signal, 0, 2**BIT_DEPTH - 1).astype(np.uint16)
    
    # 2. Windowing/Leveling: Simulating a soft contrast enhancement (e.g., favoring intermediate gray scales)
    # We scale the signal so that the average value is emphasized,
    # while clipping very dark/very bright artifacts slightly.
    mean_signal = np.mean(clipped_signal)
    windowed_signal = clipped_signal - mean_signal + np.mean(clipped_signal) # Simple normalization around the mean
    
    return windowed_signal

# 1. Simulation
raw_signal_data = simulate_absorption(None)

# 2. Processing
final_image_data = apply_processing(raw_signal_data)

# 3. Visualization
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# Plot 1: The Simulated Absorption Map (The physical reality)
im1 = axes[0].imshow(np.exp(raw_signal_data), cmap='viridis', origin='lower')
axes[0].set_title("1. Simulated Absorption (High Value = Low Absorption)")
fig.colorbar(im1, ax=axes[0], orientation='horizontal')

# Plot 2: The Raw Signal (Direct output from the detector)
im2 = axes[1].imshow(raw_signal_data, cmap='gray', origin='lower')
axes[1].set_title(f"2. Raw Signal (Simulated {BIT_DEPTH}-bit Signal)")
fig.colorbar(im2, ax=axes[1], orientation='horizontal')

# Plot 3: The Final Image (Processed data)
im3 = axes[2].imshow(final_image_data, cmap='gray', origin='lower')
axes[2].set_title("3. Processed Image (Windowed/Levelled)")
fig.colorbar(im3, ax=axes[2], orientation='horizontal')

plt.tight_layout()
plt.show()
```

**Interpretation of the Simulation:**

1.  **Column 1 (Absorption):** Shows the physical density. The bright areas (high values) are the least dense material, and the dark areas (low values) are the most dense material (the object).
2.  **Column 2 (Raw Signal):** Shows how the detector responds. It collects the maximum signal where absorption was lowest, and the minimum signal where absorption was highest.
3.  **Column 3 (Processed Image):** Shows the final, processed image. The simulated windowing/leveling step ensures that the visual contrast is optimized for human viewing, often enhancing the subtle variations that might have been lost or skewed in the raw signal data.
